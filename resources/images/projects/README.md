# Imágenes de proyectos

Los recursos de este directorio se procesan mediante Vite y se sirven con nombre versionado en
producción.

## Especificaciones

- Formato de presentación: WebP.
- Dimensiones: 960 × 600 px (relación 16:10).
- Los logos se mantienen centrados y sin deformación sobre una superficie del sistema visual.
- Las cards usan carga diferida y dimensiones explícitas para evitar saltos de layout.

## Fuentes

- cmg.webp: derivado optimizado de public/logos/CMG.png del repositorio público
  felipeAGonzalez/cmg.
- pamedic.webp: derivado optimizado de public/logos/pamedic.png del repositorio público
  felipeAGonzalez/pamedic.

SIAN/Pretyre y Proyectos personales conservan un placeholder hasta contar con recursos visuales
oficiales.
