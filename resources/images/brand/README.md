# Identidad visual

Este directorio contiene los archivos oficiales de marca:

- `Isotipo.png`: isotipo FG;
- `logotipo.png`: logotipo completo con nombre y descriptor.

Las rutas públicas se centralizan en `config/brand.php` y Vite procesa los originales sin
modificarlos. No deben recrearse, redibujarse ni sustituirse por aproximaciones. El favicon se
gestiona por separado en `public/favicon.ico` y no forma parte de este directorio.
